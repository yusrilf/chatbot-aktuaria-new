# Test Global Document

## Deskripsi
Ini adalah dokumen test untuk menguji upload dengan session_id=global.

## Konten Test
- Dokumen ini akan diupload sebagai global document
- Seharusnya dapat diakses oleh semua session
- Menggunakan endpoint /input-docs dengan session_id=global

## Informasi Tambahan
Dokumen ini berisi informasi yang relevan untuk semua pengguna sistem aktuaria.

### Fitur Global Document:
1. Dapat diakses dari session manapun
2. Disimpan dengan session_id=global
3. Muncul ketika include_global=true

## Kesimpulan
Test document untuk verifikasi fungsionalitas global document upload.
