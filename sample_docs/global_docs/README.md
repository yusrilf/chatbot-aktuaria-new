## ⚡ **Quick Reference**

### 🔤 **Essential Terminology**
- **PSAK 219** = Indonesian employee benefits accounting standard (effective 2025)
- **PUC** = Projected Unit Credit method (primary calculation approach)
- **PVDBO** = Present Value of Defined Benefit Obligation (current liability)
- **CSC** = Current Service Cost (annual expense component)
- **OCI** = Other Comprehensive Income (actuarial gains/losses)
- **KKA** = Licensed Actuarial Consulting Firm (Kantor Konsultan Aktuaria)
- **IFRIC** = International interpretation (24-year rule for liability recognition)

### 📅 **Critical Dates**
- **1 Jan 2025** = PSAK 219 mandatory effective date
- **31 Dec 2024** = Last reporting under PSAK 24
- **24 years** = IFRIC rule minimum age for liability recognition

### 🏗️ **Key Formulas**
- **PVDBO** = Present value of benefits × (years served / total years)
- **CSC** = Present value of benefits ÷ total working years
- **Total Benefit** = Severance + Service Award + Compensation (varies by regulation)

### ⚖️ **Regulatory Framework**
- **UUK (2003)** = Higher benefits, max 32.2x salary
- **UUCK (2020)** = Lower benefits, max 25.75x salary + contract worker compensation
- **PSAK 219** = Accounting treatment (replaces PSAK 24)
